# 3D Printable Case and Mounting System for the LPS Node

This repository provides 3D-printable files for the LPS node enclosure and its mounting system, supporting both vertical and horizontal mounting configurations.

### Required STL Files

| Component | Vertical Mounting | Horizontal Mounting |
|---|:---:|:---:|
| [Front.stl](Front.stl) <br/><small>Front shell of the enclosure (contains hole for the UWB)</small> | ✓ | ✓ |
| [Back.stl](Back.stl) <br/><small>Back shell of the enclosure (holds the LPS node)</small>| ✓ | ✓ |
| [Adapter.stl](Adapter.stl) <br/><small>Mounting adapter for poles, lighting stands, tripods, etc.</small>| ✓ | ✓ |
| [Horizontal-Adapter.stl](Horizontal-Adapter.stl) <br/><small>Used in combination with the Adapter for *horizontal* mounting</small>| — | ✓ |

## Assembly Instructions

- **Parts List**: See the full parts list [here](Parts-List.txt)

| Instructions                                                                                                                                                                                                                                                                                                                                                                                                                        |                                                           |
|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------|
| 1) Place the LPS node into the *back* part of the case.<br/>2) Install the toggle switch and ensure correct orientation.<br/> 3) Connect and solder the USB power cable wires.<br/>4) Lay down the USB cable on top of the designated notch in the *back* part (tie a small knot to release the tension).<br/>5) Attach the *front* part and secure it with screws.<br/>6) Use the *adapter* to mount the case on a tripod. | <img src="building-instructions.jpg" style="zoom:70%;" /> |
